# C# Zafkiel: The All-In-One Edition

This is a single-file implementation of the Kurumi Tokisaki themed prank using Windows Forms.

## 🚀 How to Build

1. Open Visual Studio.
2. Create a new **Windows Forms App (.NET)** project.
3. Replace the contents of `Program.cs` (or your main file) with the code provided.
4. Add your `GIF/tokisaki-kurumi.gif` to the project folder.
5. Set the GIF properties to **"Copy to Output Directory: Copy if newer"**.

## ✨ Features

* **Combined Logic**: No need for multiple form files; classes are bundled.
* **BSOD Simulation**: Fullscreen Windows-style crash screen with progress tracker.
* **Runaway Button**: Classic "Jessica" prank interaction.

## ⌨️ Emergency Exit

Press **ESC** at any time to close.
