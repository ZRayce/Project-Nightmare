# DefinitelyNotATimeTrap

A **parody social-engineering simulator** inspired by Kurumi Tokisaki (Date A Live).  
This project demonstrates how **emotional manipulation, urgency, and charm** are used in phishing attacks—but in a **harmless, educational way**.

⚠️ **Important:** No data is collected. No network activity. This is strictly a simulation.

├── csharp-version/ ← C# WinForms version
└── screenshots/ ← UI screenshots

## Purpose

- Learn how phishing can exploit human emotions  
- Practice **UI programming** in Python and C#  
- Show cross-language skills for cybersec projects  
- Have some **fun with Kurumi-style yandere aesthetics** 😈🕰️
